# Model Studio

Python 3.10+, стандартная библиотека и Tkinter. Запуск: python main.py.

## Проверка

python -m unittest discover -s tests -v
python tests/smoke_ui.py

smoke_ui открывает и закрывает окно, поэтому требует графическую сессию.

## Согласованная логика

Итоговый автомат: docs/Схема.drawio, контрольная сумма docs/source_sha256.txt.
Рабочий анализатор language/lexer.py выполняет состояния через явные if/elif.
117 переходов, ID M01...M29 и R001...R088. Не возвращайте табличный диспетчер исполнения.
language/transitions.py и tests/xml_oracle.py используются проверками соответствия.
TW=1, TL=2, TI=3, TN=4. Индексы с 1; отсутствие в look: z=0.
B — строковый буфер числа, gc — единственная операция чтения следующего символа.
Действия входа выполняются один раз после смены CS. Ветви без gc сохраняют CH.
TN объединяет записи по точному значению Fraction, исходные написания сохраняются.
Лексический анализ должен оставаться ручным, без генераторов лексеров и библиотек распознавания.

Схема зафиксирована пользователем как итоговая. Меняйте её только по его просьбе.
Не смешивайте лексический анализ с будущим синтаксическим; интерфейс ui/ отделён от language/.
При переносе на другое устройство сначала создайте .venv, запустите тесты, затем приложение.
